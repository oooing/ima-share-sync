# IMA Share Sync 0.3.1

## 这次更新

- **目录滚动假死容错与条目保留**：修复在 Electron/Chromium 虚拟列表中由于轻微滚动未产生百分比位移而导致整场同步中断报错的问题；引入硬件鼠标滚轮补偿重试，并在遇到滚动边界时安全保留并同步已发现条目，不再直接报错退出。
- **后台转换节流根除**：优化事件循环出让机制（`yieldEventLoop`，优先使用 `setImmediate`/`MessageChannel`），彻底根除 Chromium 在最小化或锁屏场景下对 `setTimeout(0)` 强加的 60 秒时钟对齐后台节流，大幅提升多 PDF 批量转 Markdown 的后台处理速度。
- **操作卡片状态解耦与倒计时读秒**：文章保存完成即宣布同步成功，进入 5 秒倒计时读秒自动关闭；后续 Markdown 后台转换不再卡住桌面卡片，支持用户专注当前工作。
- **卡片右上角关闭选项菜单**：原生提示卡片右上角新增 `✕ ▾` 下拉菜单，提供“关闭本次提示”与“下次不再提示 (永久关闭)”选项；选择不再提示后，后续完成提示将仅以静默读秒方式展示并自动退出。
- **动态保存进度展示**：保存文章阶段展示直观的 `(已保存数 / 总数)` 进度显示（如 `(1/16)` 至 `(16/16)`），明确了解批量处理进度。

## 安装与更新

将本发布的 `main.js`、`manifest.json`、`styles.css` 放入仓库的 `.obsidian/plugins/ima-speed-sync/`，保留 `data.json`，然后重新启用插件或重启 Obsidian。

需要 Windows 10+、Obsidian 1.11.4+ 和已登录的 IMA 桌面端。无需额外安装 Node.js。

## 验证范围

发布前通过端到端测试（E2E）、版本一致性校验、ESLint、TypeScript 静态检查、生产打包构建、全链路回归测试（包括 16/19 假死容错断言、大文件转换测试、PowerShell 离线/在线单测以及 WPF 真实窗口倒计时读秒与菜单测试）。

## English

- **Virtual List Scroll Degradation & Item Retention**: Fixed synchronization failures caused by Electron/Chromium virtual lists stalling on minor scroll increments. Added simulated mouse wheel nudge retries and graceful fallback to safely retain and sync all collected items instead of aborting the run.
- **Background Throttling Elimination**: Replaced timer yielding with `yieldEventLoop` (`setImmediate`/`MessageChannel`), eliminating Chromium's 60-second background timer clamp when Obsidian is minimized or locked.
- **Operation Card Decoupling & Auto-Countdown**: Decoupled PDF saving completion from background Markdown conversion. The card displays sync success and begins a 5-second automatic countdown to close, letting background conversion run quietly.
- **Close Options Dropdown**: Added a `✕ ▾` dropdown menu on the desktop card offering "Close this notice" and "Do not show again (Permanent)". When muted, future completion notices exit automatically after countdown without interrupting workflow.
- **Dynamic Progress Counter**: Added explicit numeric progress indicators during article saving (e.g. `(1/16)` to `(16/16)`).

Install `main.js`, `manifest.json`, and `styles.css` in `.obsidian/plugins/ima-speed-sync/`, keep `data.json`, then reload Obsidian.
