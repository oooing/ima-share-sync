# IMA Share Sync 0.1.0

把 IMA 分享里的文字内容，保存进自己的 Obsidian 知识库。

## 适合这样的你

每天在 IMA 共享知识库阅读简报、学习资料或工作笔记，希望少做复制粘贴，在 Obsidian 中继续搜索、标注和建立双向链接。

## 首个公开版本

- 通用文字文章同步，以及兼容已有使用习惯的速看预设。
- Markdown 保存、来源识别、同名文件保护及标题日期排序。
- 最近文章检查范围可配置，手动同步无需倒计时。
- 自动同步前可取消或推迟；原生小卡片显示进度、停止入口与简短结果。
- 插件侧栏内的完整同步日志：每页 20 条，收起不删除，错误可直接定位。
- 简化熊猫书本图标与可配置通知。

## 安装

下载下面的 `main.js`、`manifest.json`、`styles.css`，放入仓库的 `.obsidian/plugins/ima-speed-sync/`，再在 Obsidian 第三方插件设置中启用 **IMA Share Sync**。更新时保留现有 `data.json`。

要求：Windows 10+、Obsidian 1.11.4+、已登录并能访问目标内容的 IMA 桌面端。

## 使用边界

当前面向已验证的中文文字文章界面，不承诺完整导出 PDF、图片、附件或复杂表格。同步可能显示 IMA 窗口，不是完全后台的无界面服务。请只同步有权复制、保存的内容。
