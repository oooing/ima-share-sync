# IMA Share Sync 0.2.0

把共享文章和允许下载的原文件保存到本地，并从 PDF 生成可检索的 Markdown 笔记。

## 更新内容

- **同步范围**：新增「同步最新／全部同步」、子文件夹层级、来源目录保留、标题筛选及目录数量设置。新安装默认检查最近 30 个候选；最新是所选范围内的最新，跳过或失败不补数。
- **兼容旧规则**：旧配置继续每个目录分别计数，由用户主动迁移到整轮总量；旧速看模式继续保留。
- **原文件保存**：通过 IMA 允许的入口保存 PDF、图片和支持的音视频原件。严格确认来源与本轮阅读器归属，保护无关窗口；无法确认来源或下载权限时明确失败。
- **PDF 导入校验**：导入前解析真实页面树，拒绝伪文件、截断、空页、坏引用、循环与加密内容，支持超时和取消，校验不改写原件。
- **本地文档转换**：下载 PDF 后可生成 Markdown，保留原 PDF 双链，支持类型筛选和手动补全。转换器和 WASM 解析器内置在 main.js，无需另装 Node.js 或访问开发者源码。已有非本插件生成的笔记受保护。
- **设置与提示**：同步范围、文档转换、通知提醒、基础设置分成独立页签，设置支持中英文；调整进度卡与列表样式。

扫描件只生成关联原 PDF 的提示笔记，**不包含 OCR**。文字、混合 PDF 的复杂版式与表格不保证完全还原。部分侧栏、授权和运行提示仍为中文。

「全部同步」仍受扫描深度、标题过滤、列表读取预算和 1000 个候选保护上限约束；旧每目录规则分别应用上限，不承诺无限穷尽。

## 安装与更新

下载本页 main.js、manifest.json、styles.css，替换仓库 .obsidian/plugins/ima-speed-sync/ 中对应的三个文件，**保留 data.json**。

重新启用插件或重启 Obsidian 后，确认版本显示 v0.2.0。已开启启动同步时，重载可能触发自动同步。

Windows 10+ · Obsidian 1.11.4+ · 已安装且登录的 IMA 桌面端。只保存你获准复制或下载的内容；原文件要求当前 IMA 提供可用入口。GitHub 发布与 Obsidian 社区插件市场审核是独立流程。

## 验证范围

发布流程执行版本一致性、ESLint、TypeScript、生产构建、JavaScript 回归、PDF 页面树校验、独立 Markdown 转换、PowerShell 夹具及桌面提示卡测试。

转换专项覆盖没有系统 Node.js 查找路径和项目依赖时的运行、文字提取、类型筛选、增量跳过、已有笔记保护、无效 PDF、取消与线程错误。此版本发布检查未额外启动 IMA 或抓取实际资料；离线测试不等同于实机同步验收。

## English

This release adds scoped subfolder synchronization, permitted original-file downloads, structural PDF validation, local PDF-to-Markdown conversion, and Chinese/English settings. The converter is embedded in the three standard installation assets and requires no separate Node.js or developer checkout. Existing configurations keep their per-folder count rule until explicitly migrated. Scanned PDFs receive a linked placeholder; OCR is not included. Automated checks use fixtures and a simulated host, with no additional live IMA sync in this release run.
