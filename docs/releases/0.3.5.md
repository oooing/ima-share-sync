# IMA Share Sync 0.3.5

Fix reproducible builds across Windows and Unix by normalizing the gzip OS header in the embedded WASM asset. The parser bytes and runtime behavior are unchanged. Add Linux CI that checks the same compressed-resource digest as Windows and runs the real PDF conversion regressions.

Includes the 0.3.4 bundle-size reduction (under 5 MB), offline parser, release-asset provenance attestations and CSS selector cleanup. Community review for 0.3.4 completed and enabled installation; this release addresses the newly reported cross-platform build mismatch. README installation instructions now reflect the enabled Community listing.

The known IMA directory-list disappearance issue is not fixed. Live IMA synchronization is not part of the isolated release checks. The installed plugin and user data are not changed by publishing this release.
