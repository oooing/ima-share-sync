# IMA Share Sync 0.3.3

## 修复

- 原文件标题包含英文引号、尖括号、竖线或控制字符时，不再因 Windows PowerShell 5.1 的 `GetExtension` 路径校验导致同步中断。
- 预检与下载共用扩展名识别规则；先保留扩展名，再清洗、截断文件名主体，兼容长标题和大写后缀。
- 单条文件名预检失败时记录具体标题与原因，继续处理本轮其余候选；不改变候选顺序和数量，不补位。取消后停止处理，全部预检失败时不再提示“均为最新”。
- 控制字符替换后的连续空白与 Obsidian 实际保存名称保持一致，避免已存在文件判断不一致。
- 包含此前已在工作区完成的列表定位恢复、文件夹跳转确认及相关离线回归修复。

## 已知问题

目录扫描期间若 IMA 列表容器暂时不可读取，本版本仍可能中断并提示“目录列表在检查过程中消失”。此问题尚未修复，发生时可能尚未进入文件名预检或下载阶段。

## 验证与安装

版本一致性、lint、类型检查、生产构建、JavaScript、PDF、Markdown、PowerShell 和 WPF 预览测试通过。其中新增 130 项文件名与预检回归断言；测试使用模拟对象和隔离临时目录。

真实 IMA 同步尚未作为本次封版的验收证据。离线测试通过不代表所有来源内容已完成下载。

插件资产为 `main.js`、`manifest.json`、`styles.css`。更新前备份现用版本，保留 `data.json` 与笔记内容，更新后重新加载插件。最低要求仍为 Windows 10+、Obsidian 1.11.4+。

## English

- Parse original-file extensions from display titles instead of treating titles as Windows paths. Preserve the extension before sanitizing and truncating the stem.
- Report preflight failures per item and continue the remaining selected candidates without backfilling. Preserve cancellation and avoid an all-current message when preflight fails.
- Keep control-character whitespace normalization consistent with the final Obsidian filename.
- Includes the existing workspace fixes for list relocation and folder navigation.

Automated checks, including 130 new filename/preflight assertions, pass in isolation. Live IMA synchronization is not part of this release's verification evidence. Preserve plugin data and reload after updating the three release assets.

Known issue: a temporarily unavailable IMA list container can still abort directory scanning before filename preflight or download. This release does not fix that scanning recovery issue.
