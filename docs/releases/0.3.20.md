# IMA Share Sync 0.3.20

- Convert scanned PDFs already on disk and see conversion progress, elapsed time, upload counts and failure details. No repeat download is needed.
- Image OCR is **off by default**. Choose local layout OCR, lightweight local text OCR, or Baidu AI Studio. Install a local runtime separately; the plugin only checks its availability and uses it for manual conversion.
- Baidu requires your own token and confirmation for each batch. A confirmed upload sends the entire PDF; automatic sync never uploads documents for OCR or switches modes.
- The sidebar home now shows the panda-book logo. OCR setup appears directly under the selected mode without rebuilding the settings page.

See the [OCR setup guide](https://github.com/oooing/ima-share-sync/blob/main/docs/OCR.md). Windows only; requires Obsidian 1.11.4+. The plugin uses PowerShell for IMA, local filesystem access for files and conversion, and an optional Python process for local OCR.
