# IMA Share Sync 0.3.0

## 这次更新

- **使用统计**：新增默认打开的统计页，显示当前保存目录的实际文件数、Markdown 数量、占用空间、同步成功率和连续保存天数。
- **同步记录热力图**：支持近三个月、半年和全年视图。检查数与保存数从本次升级后的任务开始记录；旧记录不推算。节省时间按每次成功保存 10 分钟估算。
- **转换进度**：文档转换页显示进度、当前文件，以及完成后的生成、跳过和失败数量；可手动补齐已有 PDF 的 Markdown。
- **本地 PDF 转换**：调整 Obsidian 中的转换执行方式，内置 WASM 解析器，并保留已有手写笔记保护与增量跳过。批次可在文件之间响应取消；单个大型 PDF 解析期间可能暂时占用界面线程。
- **同步修复**：修正无滚动条且没有底部提示的短目录判定；文章滚动停在约 98% 时，不再仅凭停滞将其判定为正文完整。
- **界面更新**：更新设置页和桌面操作提示样式，补充统计与转换面板的中英文文案。

## 安装与更新

将本发布的 `main.js`、`manifest.json`、`styles.css` 放入仓库的 `.obsidian/plugins/ima-speed-sync/`，保留 `data.json`，然后重新启用插件或重启 Obsidian。

需要 Windows 10+、Obsidian 1.11.4+ 和已登录的 IMA 桌面端。无需额外安装 Node.js。图片扫描 PDF 仍不提供 OCR；原文件保存仍需要 IMA 提供可用的下载入口。

## 验证范围

发布前运行版本一致性、ESLint、TypeScript、生产构建、插件与统计回归、PDF 结构校验、WASM 转换、PowerShell 离线回归以及 WPF 提示卡渲染检查。本次未执行连接真实 IMA 的完整同步验收。

## English

- Added an Overview tab with actual files, Markdown count, storage size, success rate and saving streak for the selected destination.
- Added 3-month, 6-month and yearly activity views. Machine-readable sync counts start with this upgrade; older records are not estimated. Time saved is an estimate of 10 minutes per successful save.
- Added conversion progress, current-file display and completed/skipped/failed totals, alongside manual PDF-to-Markdown fill.
- Updated the local conversion path used by Obsidian, with the WASM parser bundled and authored-note/incremental protection retained. Batch cancellation is handled between files; a large PDF may temporarily occupy the UI thread during parsing.
- Fixed short folder lists without a scrollbar/footer and rejected incomplete article tails stalled around 98% scroll progress.
- Refreshed settings and desktop operation cards, with Chinese and English dashboard text.

Install the three release assets in `.obsidian/plugins/ima-speed-sync/`, keep `data.json`, then re-enable the plugin or restart Obsidian. Requirements remain Windows 10+, Obsidian 1.11.4+, and a signed-in IMA desktop app. Scanned PDFs do not receive OCR.

Validation covers automated build, lint, type, plugin/statistics, PDF/conversion, offline PowerShell and WPF rendering checks. A full sync against the live IMA app was not performed for this release.
