# IMA Share Sync 0.1.1

## 更新内容

- 插件侧栏标题旁显示版本号，例如 `v0.1.1`。
- 设置页显示当前安装版本，直接读取插件清单，升级后自动更新。
- 补充账号、网络和仓库外临时文件访问说明，准备社区插件市场审核。
- 统一源码换行符，避免不同系统构建时产生无意义的产物差异。

## 安装与更新

下载 `main.js`、`manifest.json`、`styles.css`，替换仓库 `.obsidian/plugins/ima-speed-sync/` 中对应的三个文件，保留 `data.json`。关闭再启用插件后，可在标题旁确认版本号。

仅支持 Windows，需要已安装并登录的 IMA 桌面端。GitHub 发布不代表已通过 Obsidian 社区插件市场审核。
