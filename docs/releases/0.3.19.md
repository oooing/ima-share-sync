# IMA Share Sync 0.3.19

## Highlights

- Find the plugin from Obsidian Settings search using Chinese or English terms such as “自动同步”, “PDF” and “Startup Sync”. Opens the existing settings interface; older Obsidian versions retain the previous interface.
- Fresh source-directory validation, clear guidance when a configured library or folder is missing, and long-path handling in source settings.
- Updated settings layout and quieter save feedback. Save failures still remain visible.
- Removed forced CSS overrides and broad relational selectors from plugin and preview styles. Preserved accessible labels, reduced-motion behavior and nested-dialog scroll locking.

## Permissions and limits

This Windows-only plugin intentionally uses PowerShell/child processes to interact with the installed IMA desktop app, and local filesystem access for temporary files, saving originals and PDF processing. IMA windows may appear when foreground interaction is enabled. These capabilities can continue to produce marketplace review cautions; this release does not remove or conceal them. Save only material you are permitted to copy or download.

Settings search was verified in Obsidian 1.15.1. The search entry opens the complete plugin settings page, not an individual setting. Automated regression tests cover synchronization, source identity, file safety, PDF conversion and settings rendering; this release's CSS changes do not constitute a new live-content synchronization test.
