# IMA Share Sync 0.3.21

- Keep already-mapped folder destinations pinned when remote articles are moved or merged across folders (such as subfolder items moved into a parent folder), preventing false folder-mapping conflicts during sync.
- Filter out moved-article records that belong to another mapped folder or a different folder depth when inferring destinations for newly observed folders, while keeping strict conflict checks for genuinely ambiguous unmapped folders and duplicate-path protection across distinct folder IDs.
- Ignore stale attachment index entries whose files no longer exist in the vault when gathering historical folder evidence.

Windows only; requires Obsidian 1.11.4+. This plugin continues to use PowerShell for IMA desktop automation, local filesystem access for saving originals and conversion, and an optional separate Python runtime for manual local OCR.

## 中文

- 修复远端文章跨目录移动或子目录合并回上级目录时，触发“同一目录 ID 的旧文章记录指向多个目录”导致同步失败的问题：已绑定的目录映射保持锁定，不再被后续移入的文章推翻。
- 对尚未建立映射的新目录，自动过滤归属于其他已绑定目录或路径层级不匹配的搬迁文章记录，同时保留不同目录 ID 防混存与真正歧义拦截。
- 核对历史目录位置时，忽略本地已不存在文件的失效附件索引记录。

仅支持 Windows，需要 Obsidian 1.11.4+。插件继续使用 PowerShell 与 IMA 桌面端交互、访问本地文件系统保存与转换文档，并可选调用外部独立安装的本地 Python OCR 环境。
