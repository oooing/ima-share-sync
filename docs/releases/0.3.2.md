# IMA Share Sync 0.3.2

## 修复

- 同步失败时保留提示卡，必须手动关闭；成功时继续按设置自动关闭。

- 打开来源文件夹后，确认面包屑末项已进入目标位置再读取列表，避免把知识库首页误当成目标目录。
- 当前已经位于目标文件夹时，等待列表稳定，避免重复打开。
- 扩展面包屑节点识别，过滤空节点与分隔符，兼容名称前后的空白。
- 文件夹切换支持重试；导航失败时显示当前面包屑和匹配数量，便于排查。
- 修正多级路径比对，已经位于目标子目录时避免重复导航。

## 更新

替换 `main.js`、`manifest.json`、`styles.css`，保留 `data.json`，然后重新启用插件或重启 Obsidian。最低要求仍为 Windows 10+、Obsidian 1.11.4+。

验证包含版本一致性、lint、类型检查、生产构建、JavaScript/PDF 转换、PowerShell 离线回归和 WPF 提示卡渲染。本次发布未执行真实 IMA 同步验收。

## English

- Keep failed-operation cards open until manually dismissed, while preserving automatic close on success.

- Confirm the selected folder through its final breadcrumb before reading the list, avoiding premature reads of the knowledge-base home page.
- Avoid reopening a folder that is already selected.
- Improve breadcrumb node recognition and whitespace handling.
- Retry folder navigation and include current breadcrumbs in navigation errors.
- Fix nested-path comparison to avoid unnecessary navigation.

Install the three release assets, preserve `data.json`, and re-enable the plugin or restart Obsidian. Automated validation covers build, lint, types, JavaScript/PDF conversion, offline PowerShell regressions and WPF rendering; live IMA synchronization was not verified for this release.
