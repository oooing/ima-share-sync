# 原文件同步稳健性修复

本轮只做代码修复和离线测试；未启动 IMA、未触发真实同步、未修改笔记或同步配置。

## 已修复

- 文件身份：不再按相似标题或历史缓存猜测下载地址。只接受本轮唯一、完整标题匹配的阅读器，并从该阅读器公开属性取得地址；无法确认时使用该阅读器可用的下载入口，否则明确失败。
- 窗口保护：不关闭已有阅读器、并行打开的无关窗口。只清理本轮确认归属的阅读器和保存对话框；检测到用户窗口时保留 IMA 应用。
- PDF 验证：导入前解析实际页面树，拒绝伪 PDF、空页、坏引用、循环页面树和加密内容。校验不重写原文件；后台线程有超时、取消和资源限制。
- 取消保护：覆盖旧文件前重新严格检查取消状态，包括“取消后保留已完成提取”的路径；已发出的写入不承诺回滚。
- 下载边界：只允许限定 HTTPS 服务地址，拒绝重定向，核对可用的 Content-Length，不记录带签名的下载地址。

## 尚需实机确认

当前 IMA 版本是否向公开 UIA 属性暴露阅读器 URL，需要实机验证。严格匹配、保存对话框归属检查也尚未做本轮桌面验收。没有可用下载入口的分享文件可能被明确跳过/报错，不能承诺所有分享内容都可保存。

PDF 校验确认的是结构和页面树，不代表逐一校验所有字体、图像和内容流，也不证明它与源文件逐字节相同。图片/音视频仍使用既有格式初筛，本轮未增加这些格式的完整解码校验。

本轮没有发布 GitHub Release，版本号保持 0.1.2。
