# IMA Share Sync 使用指南

[English](GUIDE.md) · **简体中文**

把 IMA 共享文章和允许下载的原文件保存到 Obsidian，供本地检索、标注与后续分析。

## 安装与更新

要求 Windows 10+、Obsidian 1.11.4+，以及已安装、已登录并有权访问目标内容的 IMA 桌面端。

1. 从 [最新发布页](https://github.com/oooing/ima-share-sync/releases/latest) 下载 main.js、manifest.json、styles.css。
2. 将这三个文件放进仓库的 .obsidian/plugins/ima-speed-sync/。
3. 更新时保留 data.json；重新启用插件或重启 Obsidian。
4. 在插件标题旁或设置页确认显示 v0.2.0。已开启启动同步时，重载可能触发自动同步。

转换器与解析依赖已内置，无需安装 Node.js、其他插件或访问开发者源码目录。GitHub 发布与 Obsidian 社区市场审核是独立流程。

## 首次同步

打开「设置 → 第三方插件 → IMA Share Sync → 同步范围」，填写知识库、源文件夹和保存位置。来源名称应与 IMA 界面一致，保存位置是当前仓库内的相对路径。

先手动执行「立即同步」，阅读并确认本地访问授权。默认关闭启动同步；测试完成后可到「基础设置」开启。自动同步前的提示卡可推迟或取消，执行中可停止。

## 同步范围

- **同步最新**：每次检查 1–30 个候选，新安装默认 30 个。默认从最近更新的 1 个文件夹取内容，向下 1 层。不是整棵目录树全局最新。
- **全部同步**：扩大检查范围，仍受扫描深度、标题筛选、列表读取预算和 1000 个候选保护上限约束；旧每目录规则分别应用数量上限，不承诺无限穷尽。
- **保留目录**：在保存位置创建来源同名目录。包含子级时保留来源相对层级。
- **高级设置**：最新模式目录上限 1–20 个，向下最多 5 层；标题可按关键词、前缀或正则筛选。

新安装采用整轮总量规则。例如设为 7 个文件、2 个目录，合计最多 7 个。跳过、重复、失败和不足不会补抓更旧内容。

旧配置继续每个目录分别计数，只有主动点击迁移按钮才切换整轮总量。详见 [数量与目录规则](general-selection.md)。旧速看模式保留原有排版和选择行为。

## 原文件与 PDF

文章正文保存为 Markdown；PDF、图片和部分音视频原文件只通过 IMA 可用的下载入口保存。遇到权限限制、无法确认来源、没有可用下载入口或格式不正确时会明确失败或跳过。

PDF 导入前检查真实页面树，拒绝伪文件、截断、空页、坏引用、循环结构与加密文件。校验不修改原件，也不保证所有字体、图像和内容流均可正常呈现。

## 文档转换

在「文档转换」页可开启下载 PDF 后自动转为 Markdown、选择转换范围并插入原 PDF 双链。「手动补全 → 立即补全」扫描当前有效保存目录及其子目录。

- 文字与混合 PDF 尽量提取已有文字；版式与复杂表格不保证完全还原。
- 没有可提取文字的扫描件生成关联原 PDF 的提示笔记，不包含 OCR。
- 已有较新的转换笔记跳过；已有非本插件生成的笔记受到保护。
- 转换在本地后台线程运行，可取消。失败保留错误信息，不会删除源 PDF。

## 设置与日志

设置页分为「同步范围／文档转换／通知提醒／基础设置」。基础设置可选择跟随 Obsidian、简体中文或 English；部分侧栏、授权和运行日志仍使用中文。

点击文章在 Obsidian 主编辑区阅读。同步日志每页 20 条，异常入口定位对应记录。通知页可控制自动成功、自动失败、手动结果、角标与桌面卡片。

## 数据与访问

只保存你有权复制或下载的内容；不解锁付费、不绕过权限。默认同名不覆盖；无法确认同一来源时保留已有文件。

插件通过 Windows UI 自动化、PowerShell 和本地 PDF 解析读取内容，可能显示 IMA 窗口。同步脚本使用 Windows 临时目录，结束时尝试清理；PDF 转换在本地后台线程执行。诊断日志位于 %LOCALAPPDATA%\ima-speed-sync\sync.log，可能包含标题与错误。

无遥测或自有上传服务；IMA 下载仍需联网。你配置的云端 Agent 或笔记同步服务可能上传授权内容。隐私与故障信息见 [安全说明](../SECURITY.md)。

## 开发与验证

独立源码使用 npm ci 与 npm run check；生产产物在 dist/，无需手工复制脚本或解析依赖。自动测试覆盖离线逻辑和模拟宿主，不等同于真实 IMA 桌面同步验收。
