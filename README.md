## 适合谁用

### 跟踪研报

**适合谁**：个人研究者、投研从业者，尤其是常看 IMA 分享研报的人。

**举个例子**：你关注机器人行业，把研报存下来，再让本地 AI 比较本周与上月的观点，并附上原文依据。

### 观察竞品

**适合谁**：产品经理、独立开发者，需要跟踪同类产品的人。

**举个例子**：你在做笔记工具，把 IMA 中的同类产品分析存下来，比较功能和定价，再规划下一次更新。

### 准备写作

**适合谁**：自媒体作者、内容编辑，需要找案例和原文出处的人。

**举个例子**：准备写一篇 AI 应用观察，先保存别人分享的案例，再让本地 AI 整理不同观点，写作时回查原文。

*插件负责保存资料；上述 AI 用法需要你自行配置工具。*

## 现有功能

| 功能 | 能做什么 |
| --- | --- |
| **文章保存** | 把获准保存的 IMA 文章存成 Obsidian 笔记，可搜索、标注，并与已有笔记一起查看。 |
| **原件保存** | 通过 IMA 可用的下载入口，保存 PDF、图片和支持的音视频原文件。 |
| **按需保存** | 检查最近 1–30 份资料，或扩大保存范围；可按标题筛选，批量保存也有数量限制。 |
| **保留分组** | 可检查子文件夹，设置查找层数与文件夹数量，并按来源文件夹名称存放。 |
| **生成笔记** | 从 PDF 提取已有文字并生成笔记，可附原件链接；扫描版只生成提示笔记。 |
| **补齐笔记** | 给已保存的 PDF 手动补上缺少的笔记，不用重新下载原文件。 |
| **重复跳过** | 默认跳过已识别保存过的文章，减少重复保存。 |
| **保护笔记** | 默认不覆盖同名文件；转换 PDF 时，保护非本插件生成的笔记。 |
| **导入检查** | 导入前检查 PDF；发现文件损坏或受保护时，会提示原因。 |
| **保存控制** | 可手动开始，或开启启动时自动保存；自动保存前可推迟、取消，执行中可停止。 |
| **保存记录** | 查看每次保存的文章与结果；出错时，可定位到对应记录。 |
| **进度提醒** | 查看保存进度，按需设置结果提醒、角标和桌面提示。 |
| **设置语言** | 设置页可跟随 Obsidian，或选择中文、英文；部分侧栏和运行提示仍为中文。 |
