## Who it is for

### Follow research

**For**: Individual researchers and investment-research professionals who regularly read reports shared through IMA.

**For example**: You follow robotics. Save shared reports, then ask your own local AI tool to compare this week's views with last month's and cite the original material.

### Watch competitors

**For**: Product managers and independent developers keeping up with similar products.

**For example**: You are building a note-taking app. Save IMA articles about similar products, compare features and pricing, and use them to plan your next update.

### Prepare to write

**For**: Writers and editors who need examples and original sources.

**For example**: You are writing about AI apps. Save shared examples, ask your own local AI tool to organize contrasting views, and check the sources as you write.

*The plugin saves material. The AI uses above need tools you configure separately.*

## Available features

| Feature | What it does |
| --- | --- |
| **Save articles** | Save IMA articles you are allowed to keep as Obsidian notes to search, annotate, and read alongside existing notes. |
| **Keep originals** | Save PDFs, images, and supported audio or video files through IMA's available download routes. |
| **Choose material** | Check 1–30 recent items or widen the scope. Filter by title; bulk saving still has item limits. |
| **Keep folders** | Include subfolders, set search depth and folder counts, and organize saved files using source folder names. |
| **Make notes** | Extract existing PDF text into notes, with optional links to originals. Image-only scans get placeholder notes. |
| **Fill missing notes** | Create missing notes from saved PDFs without downloading the originals again. |
| **Skip saved articles** | Recognized saved articles are skipped by default to reduce duplicate saving. |
| **Protect notes** | Same-name files are not overwritten by default. PDF conversion protects notes created outside this plugin. |
| **Check PDFs** | Check PDFs before import and show a reason when a file is damaged or protected. |
| **Control saving** | Start manually or enable startup saving. Defer or cancel before automatic saving begins, and stop a running save. |
| **Review results** | See the articles and results from each save. Locate the corresponding record when something fails. |
| **See progress** | View progress and choose result notifications, badges, and desktop reminders. |
| **Choose a language** | Settings can follow Obsidian or use Chinese or English. Some sidebar and runtime messages remain in Chinese. |
